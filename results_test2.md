## D2. 파이썬 리스트 컴프리헨션 설명해줘
- **확인 포인트:** 일반 지식으로 정상 답변
- **검색된 페이지:** 
- **힌트:** ✅ 정상

### 답변

파이썬 리스트 컴프리헨션(list comprehension)은 **기존 리스트(또는 다른 iterable)에서 원하는 형태의 새로운 리스트를 한 줄의 표현식으로 간결하게 만들** 수 있는 문법입니다. 기본 형태는 다음과 같습니다.

```python
[표현식 for 변수 in 반복가능객체 if 조건]
```

- **표현식**: 새 리스트에 들어갈 요소를 정의합니다. 기존 요소를 변형하거나 계산한 결과를 넣을 수 있습니다.  
- **for 변수 in 반복가능객체**: 원본 iterable을 순회하면서 각 요소를 `변수`에 할당합니다.  
- **if 조건** (선택 사항): 해당 요소가 조건을 만족할 때만 표현식이 실행됩니다.

### 예시
1. **숫자 1~5 제곱 리스트 만들기**
   ```python
   squares = [x**2 for x in range(1, 6)]
   # 결과: [1, 4, 9, 16, 25]
   ```

2. **짝수만 추출**
   ```python
   evens = [x for x in range(10) if x % 2 == 0]
   # 결과: [0, 2, 4, 6, 8]
   ```

3. **문자열 리스트에서 대문자만 추출 후 소문자로 변환**
   ```python
   words = ["Apple", "banana", "Cherry"]
   lower_caps = [w.lower() for w in words if w[0].isupper()]
   # 결과: ['apple', 'cherry']
   ```

### 장점
- **가독성**: 복잡한 `for`·`if` 블록을 한 줄로 요약해 코드가 짧고 명확해집니다.  
- **성능**: 일반 `for` 루프보다 약간 빠른 경우가 많습니다(특히 C 레벨 구현인 `list.append`를 내부적으로 사용하기 때문).  
- **함수형 스타일**: `map`, `filter`와 비슷한 기능을 더 직관적으로 표현합니다.

### 주의점
- 너무 복잡하게 중첩된 컴프리헨션은 오히려 가독성을 해칠 수 있으니, 2~3 단계 정도가 적당합니다.
